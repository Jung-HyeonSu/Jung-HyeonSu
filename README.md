## Interests
 
<h4>백엔드 성능</h4>
<p>대량의 요청이 몰릴 때 <b>병목이 어디에 생기는지</b> 찾고, 구조로 푸는 일에 관심이 많습니다.<br/>
처리량과 정합성을 함께 지키는 비동기 처리, 동시성 제어, 쿼리 최적화를 공부하고 있습니다.</p>
<h4>아키텍처</h4>
<p>AI로 코드를 빠르게 만들 수 있게 된 지금, <b>가장 중요한 건 구조</b>라고 생각합니다.<br/>
코드를 쓰는 속도가 빨라질수록, 그 코드를 이해하고 바꾸는 비용은 구조가 결정하기 때문입니다.<br/>
그래서 기능을 만들 때도 동작보다 먼저, 어디에 두고 어떤 경계로 나눌지부터 고민합니다.</p>
<h4>AI와 개발</h4>
<p>AI가 만든 코드는 <b>믿기 전에 검증</b>해야 한다고 생각합니다.<br/>
의도와 작업 규칙은 문서(prose)로 남겨 AI가 맥락을 읽게 하고,<br/>
결과는 정적 검증과 테스트로 먼저 걸러 사람이 검토할 부분을 줄이는 방식으로 업무를 진행하고 있습니다.</p>
